# 网易云桌面歌词

给网易云音乐电脑版用的桌面歌词：透明、置顶、可以鼠标穿透，歌词快慢能按 0.01 秒微调。
它直接读网易云自己的播放进度，所以比靠猜进度的歌词软件准。

A desktop lyric bar for NetEase Cloud Music on Windows. It reads the player's own playback
position, so the lyrics stay in sync. The interface is in Chinese.

## 下载安装

1. 到 [Releases](../../releases/latest) 下载 zip，解压到一个固定的位置。
2. 双击「安装.bat」，桌面出现「网易云桌面歌词」，歌词条自动打开。

需要 Windows 10 / 11 和网易云音乐电脑版 3.x，不用装 Python。

## 怎么用

- 在网易云里放歌，歌词自动出现在屏幕下方。
- 鼠标移到歌词上会出现工具条：左边调样式（翻译、下一句、逐词、渐变、字号、配色），右边是功能（快慢、找词、锁定、隐藏）。
- 拖动歌词条换位置，拖左右边缘改宽度。右下角托盘的红色「词」图标，右键可以改设置、退出。

| 快捷键 | 作用 |
|---|---|
| Ctrl+Alt+= / Ctrl+Alt+− | 歌词提前 / 推迟 0.01 秒（加 Shift 是 0.1 秒） |
| Ctrl+Alt+0 | 偏移归零 |
| Ctrl+Alt+L | 锁定 / 解锁（锁定后鼠标可以穿透歌词） |
| Ctrl+Alt+H | 显示 / 隐藏 |

## 常见问题

- **歌词整体快了或慢了**：调一次偏移，所有歌都生效。只有某一首不准，把工具条上的「全部歌曲」切成「只调这首」再调。
  用蓝牙耳机时声音会晚一点，一般往「推迟」调。
- **没有歌词，或显示「纯音乐」**：点「找词」，会去网易云的其他版本、LRCLIB、QQ 音乐找。填上的不对，点「撤词」。
- **拖了进度条以后歌词不准**：程序会自动听一下正在放的声音把歌词对准，等 1～2 秒即可。
- **杀毒软件报毒**：程序需要读取网易云的播放进度，选择「允许」即可。
- **提示「读不到网易云的播放进度」**：先把网易云更新到最新版；还不行请提 [Issue](../../issues)。
- **其他问题**：运行 `NeteaseLyrics.exe --selftest`，把 `data\selftest.log`（以及 `data\crash.log`，如有）附在 [Issue](../../issues) 里。

## 说明

- 非网易云官方软件。歌词在播放时从公开接口获取，设置和缓存都只存在程序目录的 `data\` 里。
- 安装包不含「按声音校准每个字」和「AI 听写」（需要 NVIDIA 显卡和几 GB 模型），想用请[从源码运行](#从源码运行)。
- MIT 协议。读取播放进度的方法来自 [Kxnrl/NetEase-Cloud-Music-DiscordRPC](https://github.com/Kxnrl/NetEase-Cloud-Music-DiscordRPC)，见 `THIRD_PARTY_NOTICES.md`。

## 更多细节

### 工具条

- **译 / 下句**：翻译和下一句可以同时显示。
- **逐词**：唱到哪个词，出现哪个词。
- **渐变**：唱到哪里，字就从左到右变色。
- **间奏**：没人唱的时候标出（前奏）（间奏）（尾奏）。
- **配色**：7 种预设，也可以自己挑颜色。
- **全部歌曲 / 只调这首**：偏移对所有歌生效，还是只对当前这首。
- **找词 / 撤词**：见下面。
- **校准**：按这首歌的声音重新对齐每个字（需要显卡功能）。

### 找词

网易云没有歌词、或者把歌标成纯音乐（冷门歌常被误标）时，不会自动去找，点「找词」才找：

- 去网易云的其他版本、LRCLIB、QQ 音乐找同一首歌：歌名、歌手要对上，版本要一样（Live、伴奏、Remix、翻唱等算不同版本），
  时长差不超过 3 秒。时间明显是乱打的歌词（好几句挤在一秒里）不要。
- 有显卡功能时，会先听一遍这首歌，确认大部分句子确实在它标的时间附近唱出来才填；整体偏早或偏晚会自动挪正。
  都对不上时可以改用 AI 听写（托盘里可以关）。
- 安装包版没法听，只填时长几乎一样的版本，偶尔会对不准，点「撤词」即可。

### 拖进度条之后

网易云自己的播放进度在拖动进度条后，可能和实际放出的声音差将近 1 秒。程序会在拖动后听 1～2 秒电脑正在放的声音，
和这首歌的缓存比对，把歌词对准，之后每 30 秒再核对一次。声音只在内存里比对，不保存、不上传；托盘里可以关掉。
蓝牙耳机自身的延迟还需要用偏移调一次。

### 从源码运行

```bat
py -m pip install -r requirements.txt
pythonw main.pyw
```

显卡功能（需要 NVIDIA 显卡）：先按 `requirements-ai.txt` 里的说明装 PyTorch，再 `py -m pip install -r requirements-ai.txt`。
装好后多出：

- 自动校准：每首歌第一次放时，后台按声音把每个字的时间对准，结果缓存下来，下次直接用。
- 找词时听歌核对、AI 听写。
- 模型（Whisper large-v3 约 3GB、Demucs）第一次用时下载到 `data\models\`；后台进程 5 分钟没活干就退出，把显存还给游戏。

自己打包：`py build_release.py`（不会把 `data\` 里的设置、缓存、日志打进去）。

### 原理

- 网易云 3.x 的系统媒体接口只给歌名、不给播放进度，所以一般歌词软件只能猜。这里直接读网易云内存里的播放进度、
  歌曲 ID 和播放状态，和它自己的进度条同一个来源。网易云大版本更新后如果读不到，需要更新 `ncm_reader.py` 里的特征码。
- 只有整句时间的歌，逐词时间按音节数估算；开了自动校准会换成按声音对齐的时间。
- 校准、核对、听写用的音频来自网易云自己的缓存，不录音。

### 文件

| 文件 | 作用 |
|---|---|
| `main.pyw` | 入口：托盘、快捷键 |
| `ncm_reader.py` | 读网易云播放进度 |
| `audiosync.py` | 拖进度条后听声音对准 |
| `lyrics.py` | 取歌词、解析、找词 |
| `overlay.py` | 歌词窗口 |
| `worker.py` / `worker_client.py` | 后台显卡进程（校准、核对、听写） |
| `align.py` / `transcribe.py` | 按声音对齐每个字 / 分离人声和听写 |
| `config.py` | 设置（`data\config.json`） |
