# 网易云桌面歌词

自己做的网易云音乐（PC 3.x）桌面歌词：透明、置顶、可鼠标穿透，偏移能按 0.01 秒微调。

## 用法

- 双击桌面「网易云桌面歌词」。右下角托盘出现红色「词」图标就是开着了。
- 在网易云里放歌，歌词自动出现在屏幕下方。
- 鼠标移到歌词上会出现工具条：
  - `−0.1 / −0.01 / +0.01 / +0.1`：调偏移。**+ 是歌词提前，− 是歌词推迟**。
  - 中间那个显示偏移的按钮：滚轮 ±0.01 秒，按住 Shift 滚 ±0.1 秒，右键归零。
  - 「全部歌曲 / 只调这首」：点一下切换。平时调「全部歌曲」（耳机、音箱的固有延迟），某首歌词本身对不齐再切到「只调这首」，那首歌会单独记住。
  - 译：显示翻译。下句：在当前歌词下面预告下一句，点掉就只剩当前这一句。
  - A− A+ / 配色 / 锁定 / ✕（隐藏）。
- 拖动歌词条移动位置，拖左右边缘改宽度。
- 锁定后鼠标能穿透歌词，鼠标移上去右上角会出现「解锁」。点托盘图标也能解锁。

## 快捷键（任何时候都能用）

| 按键 | 作用 |
|---|---|
| Ctrl+Alt+= / Ctrl+Alt+− | 歌词提前 / 推迟 0.01 秒 |
| Ctrl+Alt+Shift+= / − | 提前 / 推迟 0.1 秒 |
| Ctrl+Alt+0 | 当前偏移归零 |
| Ctrl+Alt+L | 锁定 / 解锁 |
| Ctrl+Alt+H | 显示 / 隐藏 |

（小键盘的 + − 也行）

## 原理

- 网易云 3.x 的系统媒体接口（SMTC）只给歌名、不给进度，所以普通歌词软件只能靠猜。
  这里直接读网易云自己内存里的播放进度、歌曲 ID 和播放/暂停状态，跟网易云自己的进度条同一个来源。
- 网易云大约每 30 毫秒写一次进度；程序在两次之间用本机高精度时钟补齐，误差在几毫秒内。
- 歌词从网易云公开接口取，有逐字时间轴的歌会逐字变色，没有的整句变色。下载过的存在 `data/cache/`。
- 定位进度用的特征码来自 [Kxnrl/NetEase-Cloud-Music-DiscordRPC](https://github.com/Kxnrl/NetEase-Cloud-Music-DiscordRPC)。
  网易云大版本更新后如果特征码失效，歌词条会提示「读不到网易云的播放进度」，需要更新特征码。

## 文件

- `main.pyw` 入口：托盘、全局快捷键、只允许开一个
- `ncm_reader.py` 读网易云播放进度 + 平滑时钟
- `lyrics.py` 取歌词、解析 LRC / 逐字 YRC、缓存
- `overlay.py` 歌词窗口
- `config.py` 设置（存在 `data/config.json`）

依赖：Python 3.12、PySide6-Essentials、requests、pywin32。
