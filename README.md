# 网易云桌面歌词

自己做的网易云音乐（PC 3.x）桌面歌词：透明、置顶、可鼠标穿透，偏移能按 0.01 秒微调。

## 用法

- 双击桌面「网易云桌面歌词」。右下角托盘出现红色「词」图标就是开着了。
- 在网易云里放歌，歌词自动出现在屏幕下方。
- 鼠标移到歌词上会出现工具条。**左边是字幕样式，右边是功能**：
  - 左边（样式）
    - 译：显示翻译。下句：在当前歌词下面预告下一句，点掉就只剩当前这一句。
    - 逐词：一句歌词不一下子全出来，而是唱到哪个词出哪个词（中文按字，英文按单词），每个词淡入一下。
    - 渐变：唱到哪里，白字就从左到右变成主题色（网易红、暖金……）。关掉就没有这个动画，整句直接是主题色；
      两种状态的描边完全一样。
    - 间奏 ▾：没人唱的时候显示什么——不显示 / 只标「（前奏）（间奏）（尾奏）」/ 标出在响什么
      （「（人声采样）」「（贝斯独奏）」「（鼓独奏）」「（钢琴）」「（唢呐声）」……）。
    - A− A+ / 配色。
  - 右边（功能）
    - `−0.1 / −0.01 / +0.01 / +0.1`：调偏移。**+ 是歌词提前，− 是歌词推迟**。
    - 中间那个显示偏移的按钮：滚轮 ±0.01 秒，按住 Shift 滚 ±0.1 秒，右键归零。
    - 「全部歌曲 / 只调这首」：点一下切换。平时调「全部歌曲」（耳机、音箱的固有延迟），某首歌词本身对不齐再切到「只调这首」，那首歌会单独记住。
    - 校准：觉得这首的逐字对不上，点一下，按这首歌的音频重新对齐每个字（20～30 秒，进度显示在歌词下面）。
    - 锁定 / ✕（隐藏）。
- 拖动歌词条移动位置，拖左右边缘改宽度。
- 锁定后鼠标能穿透歌词，鼠标移上去会在原来「锁定」的位置出现「解锁」，同一个地方点就能来回切。点托盘图标也能解锁。
- 自动补歌词：网易云这首歌没歌词时，会依次去网易云的其他版本、LRCLIB、QQ音乐找同名同歌手、时长差不到 3 秒的版本，
  找到会提示「已从 xx 补上」。托盘菜单「网易云没词时自动补歌词」可以关掉。网易云标了「纯音乐」的不会去找。
- AI 听写：上面几家都没有时，用显卡把这首歌「听」出来。歌词条会显示进度（等缓存 → 分离人声 → 识别歌词），
  一般 20～30 秒出词，之后同一首歌直接用存好的结果。听写出来的会提示「可能有听错的地方」。
  托盘菜单「哪儿都没词时用 AI 听写」可以关掉。

## 快捷键（任何时候都能用）

| 按键 | 作用 |
|---|---|
| Ctrl+Alt+= / Ctrl+Alt+− | 歌词提前 / 推迟 0.01 秒 |
| Ctrl+Alt+Shift+= / − | 提前 / 推迟 0.1 秒 |
| Ctrl+Alt+0 | 当前偏移归零 |
| Ctrl+Alt+L | 锁定 / 解锁 |
| Ctrl+Alt+H | 显示 / 隐藏 |

（小键盘的 + − 也行）

## 原理

- 网易云 3.x 的系统媒体接口（SMTC）只给歌名、不给进度，所以普通歌词软件只能靠猜。
  这里直接读网易云自己内存里的播放进度、歌曲 ID 和播放/暂停状态，跟网易云自己的进度条同一个来源。
- 网易云大约每 30 毫秒写一次进度；程序在两次之间用本机高精度时钟补齐，误差在几毫秒内。
- 歌词从网易云公开接口取，有逐字时间轴的歌会逐字变色，没有的整句变色。下载过的存在 `data/cache/`
  （别处补来的存为 `<歌曲ID>.alt.json`，没找到的 3 天后再找一次）。
- 只有整句时间的歌，逐词出现用的是估算时间：按音节数（中文一字一个、英文数元音组）把这句的时长分给每个词，
  并且一句最多按每音节 0.42 秒唱，不会把一句短词拉长到整段间奏。真有逐字时间轴的歌用真实时间。
- 定位进度用的特征码来自 [Kxnrl/NetEase-Cloud-Music-DiscordRPC](https://github.com/Kxnrl/NetEase-Cloud-Music-DiscordRPC)。
  网易云大版本更新后如果特征码失效，歌词条会提示「读不到网易云的播放进度」，需要更新特征码。

## 自动校准怎么做的

- 每首歌第一次放时，歌词先照常显示，同时在后台用这首歌的音频把每个字对齐，好了会换上并提示「已按音频校准 N 句」。
  结果存成 `data/cache/<歌曲ID>.align.json`，以后再放直接用；网易云的歌词改了会自动重新校准。
  托盘「按音频自动校准逐字时间」可以关掉，工具条「校准」可以手动重来。
- 做法：从网易云缓存取音频 → 分离人声 → 每一句单独切一个小窗（从这句附近人声真正响起的地方开始，到下一句开始），
  用 Whisper 把已知的歌词文字对到声音上 → 每个字的起止再贴到人声真正有声音的地方。
  （试过几句一起对：Whisper 会把句子之间的停顿算给下一句第一个字，句首早好几秒，所以改成一句一窗。）
- 只有整句时间的歌：每个字换成对齐出来的时间（变成真正的逐字，会有逐字变色）；如果整句时间偏晚，句首也提前到人声开始处。
- 网易云本来就有逐字时间的歌：不改它字和字之间的间隔，只在「网易云说这句开始的地方人声是静的、而附近有明确的人声起点」时整句挪过去。
- 在缓存里有网易云逐字歌词的歌上打分（给句首加了 ±0.3 秒随机误差模拟不准的整句时间）：
  - 句首：误差中位数 0.03～0.10 秒，88～96% 在 0.25 秒内。
  - 句内每个字：日语从原来估算的 0.8 秒左右降到 0.24～0.35 秒；英语和原来估算差不多（0.2～0.35 秒）。
- 没校准时的估算也改了：日语按假名拍子算（汉字约两拍，小写假名半拍以下），比原来每字一拍准一些。

## 间奏标注怎么做的

- 「间奏」：上一句唱完（按逐字时间算）到下一句开始之间空了 4 秒以上，唱完 0.8 秒后出现标注，下一句开始时消失。
  第一句之前是「前奏」（开头几秒先显示歌名），最后一句唱完 2 秒后是「尾奏」。纯音乐整首都在第二行显示。
- 「标出在响什么」：和自动校准共用同一次人声分离（第一次放这首歌时后台做一次，存成 `<歌曲ID>.scenes.json`），
  - 人声采样 / 贝斯独奏 / 鼓独奏：看分离出的人声、贝斯、鼓、其他乐器四轨谁最响，不靠猜。
  - 其他乐器的名字：用 CLAP（laion/clap-htsat-unfused）在「其他乐器」那一轨上从固定的乐器表里挑，把握不够或者不到 2 秒就不标，
    只显示「间奏」。
  - 中国乐器（唢呐、二胡、古筝、琵琶、笛子）只在歌名/歌手/歌词是中文的歌里才会标，而且要更有把握：
    在电子乐上 CLAP 会把合成器听成二胡、笛子，把握高达 0.86，光靠阈值挡不住。
  - 风琴容易被合成器铺底音冒充，也要更有把握。
  - 先试过专门的音乐版 CLAP（larger_clap_music），在现在的 transformers 版本下对什么声音都给几乎一样的结果，没法用。
- 准确度没有标准答案可对：确认过分离出的鼓轨→鼓、贝斯轨→贝斯、人声轨→人声；乐器名是「大概是这个」，不一定对。

## AI 听写怎么做的

- 音频来自网易云自己的缓存（`Cache\Cache\<歌曲ID>-<码率>-*.uc`，就是原始音频每个字节异或 0xA3），
  所以第一次放就能听写，不用录音。缓存没下完会等它（最多 90 秒）。
- 先用 Demucs（htdemucs）把人声从伴奏里分出来，再用 Whisper large-v3（faster-whisper，显卡 float16）带逐字时间听写。
- 语言：从歌曲几个地方抽样判断，再参考歌名的文字（有假名→日语、有韩文→韩语、只有汉字→中文，除非声音明显不是）。
  中文会提示用简体。
- 人声检测阈值调松了（默认值是给说话用的，会把唱的句子当静音丢掉）：在几首缓存歌上对比，
  文字吻合 38～79%，句子开头时间误差中位数 0.36～0.53 秒。伴奏很重、人声很少或做了特殊处理的歌会听得很差。
- 过滤：Whisper 在静音处常编的「字幕 / 谢谢观看 / 订阅」之类整句丢掉；把握太低的句子丢掉；同一句连续重复太多次截掉。
- 听写在单独的进程里跑（`transcribe.py`），跑完就退出，显存和内存都还回去；歌词窗口本身不加载 PyTorch。
  切歌会立刻停掉上一首的听写。失败原因记在 `data/ai_errors.log`。
- 模型在 `data/models/`（约 3.2GB），PyTorch 装在 Python 里（CUDA 12.8 版，50 系显卡要这个版本）。

## 文件

- `main.pyw` 入口：托盘、全局快捷键、只允许开一个
- `ncm_reader.py` 读网易云播放进度 + 平滑时钟
- `lyrics.py` 取歌词、解析 LRC / 逐字 YRC、缓存、别处补歌词、逐词时间估算
- `overlay.py` 歌词窗口
- `transcribe.py` AI 听写（单独进程运行）
- `align.py` 按音频校准逐字时间 + 间奏标注（单独进程运行，一次分离两样都做）
- `scenes.py` 间奏里在响什么
- `config.py` 设置（存在 `data/config.json`）

依赖：Python 3.12、PySide6-Essentials、requests、pywin32；AI 听写 / 校准 / 间奏标注另需 torch（cu128）、demucs、
faster-whisper、transformers。
